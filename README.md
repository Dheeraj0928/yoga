## 🚦 Getting Started

### Prerequisites
No special prerequisites required. Just a modern web browser!

### Installation

1. Clone the repository:
```bash
git clone <repository-url>
cd "wti space"
```

2. Open any project folder in your preferred directory:
```bash
# For example, to view the WTISpace brand page:
cd pages/brand
```

3. Open `index.html` in your web browser:
   - Simply double-click the `index.html` file, or
   - Use a local development server (recommended)

### Using a Local Development Server (Optional)

For better development experience, use a local server:

#### Using Python:
```bash
# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000
```

#### Using Node.js (http-server):
```bash
npx http-server -p 8000
```

Then navigate to `http://localhost:8000/pages/[project-name]/index.html`
